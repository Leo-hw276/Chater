# Chater

Chater is a polished, single-file AI chat workspace prototype with a dark glassmorphism interface, conversation sidebar, prompt starters, model header, and responsive layout.

## Run

Open `index.html` in a browser. No build step is required.

## Connect an AI backend

Replace the demo response in the inline script with your own secure backend endpoint. Keep API keys on the server; never place production secrets in this HTML file.
